Coursework in practice

Django Marketplace

Python / Django / MariaDB / REST API

The problem: buyers and vendors need different ways to browse products, manage stores, place orders and access reviews.

The approach: role-based permissions separate their workflows. Vendor and store navigation helps buyers find products; a cart, bounded quantity and rating inputs, checkout and invoices support the purchase flow. MariaDB stores application data, and tests check permissions and key behaviours.

Newsroom

Python / Django / MariaDB / REST API

The problem: readers, journalists and editors need distinct publishing and subscription workflows.

The approach: role-aware accounts and permission checks control content creation and approval. Publisher management pages connect editors and journalists to organisations. Approval callbacks support notifications and API publication, while automated tests check registration, ownership and access rules.

View newsroom source ↗

Sticky Notes

Python / Django / HTML / CSS

The problem: personal notes need to be easy to manage while remaining private to their owner.

The approach: an authenticated Django application provides note creation, viewing, editing and deletion. Ownership checks restrict access, and automated tests verify the core workflows.
