# MyCV

Khethelo Ntsele's online CV for the static website deployment practical.

## Run locally

Open `index.html` in a browser. Keep `style.css` beside it. No dependencies or build step are required.

## Deployment

GitHub Pages serves the `main` branch from the repository root. The home page is `index.html`.

## Content

This CV describes HyperionDev coursework and links to the marketplace, newsroom and sticky notes projects. Project work is identified as educational experience. No employment history, dates, qualifications, private contact details or project metrics have been invented. Contact is through the public GitHub profile.
